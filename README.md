# 学校视力筛查 · 限期回传台

家长不把完整病历交给校医，只发放**带截止时刻、按字段限定**的回传授权；校医在授权范围与期限内提交左右眼裸眼视力与复查建议。

## 业务规则

- 页面顶部可切换 **家长 / 校医** 两个身份（选择会持久化）。
- **家长端**
  - 勾选允许校医填写的字段：左眼裸眼视力、右眼裸眼视力、复查建议；
  - 设定截止时刻后发布；可**撤回授权**，撤回后校医新提交立即关闭；
  - 撤回 / 过期后可重新设定范围与截止时刻再次发布；
  - 可查看所有已接收的回传记录及当时的授权快照；
  - 处方与家庭资料仅家长端显示与编辑。
- **校医端**
  - 只能看到授权范围内的字段与已接收记录；
  - 未发布、已撤回、已截止时表单冻结；
  - 越权字段、过期 / 撤回后提交：规则层一律挡下并提示原因，**输入内容保留**（草稿持久化，重开仍在）；
  - 授权字段必填，视力须为五分记录（4.0–5.3）或小数记录（0.1–2.0）；
  - 提交成功后只落库家长授权的字段（白名单）。

## 架构：规则 / 存取 / 页面分离

```
src/
  rules/        纯业务规则，不依赖 React 与 localStorage
    fields.ts          字段目录、角色可见性
    authorization.ts   授权状态、截止时刻、撤回判定与倒计时
    submission.ts      提交校验、拦截原因、白名单落库
  storage/
    repository.ts      localStorage 读写、首次示例数据、useStoredState
  components/
    ParentConsole.tsx  家长端
    NurseConsole.tsx   校医端
    shared.tsx         状态徽标、提示横幅、回传记录列表
  App.tsx              角色切换与组装
```

授权、回传记录、校医草稿、处方与家庭资料均保存在浏览器 localStorage，重开页面仍然可见。
